## 🌎 Overview

**BookMeThat** is built with modern performance techniques (such as lazy-loaded hydrates, logical CSS layouts, and parallel thread image loading) to provide travelers with direct access to global eSIM connections, local motor rentals, passenger restitution services, and travel cybersecurity. 

It contains a dual-layer workspace:
1. **The Interactive Lab Simulator**: Evaluate Largest Contentful Paint (LCP), Cumulative Layout Shift (CLS), and Interaction to Next Paint (INP) under simulated Edge cache regions.
2. **Jamstack Static File Exporter**: A clean, physical-to-logical asset compiler producing compliant semantic HTML5 templates, logical properties stylesheet bases, and under-5KB vanilla ES6 modular engines.

- **Dynamic Logistics Hub**: Interactive comparison calculators for travel budgeting:
  - **Cellular Data Plan Estimator**: Accurately predict roaming data needs.
  - **Car Hire Deposit Risk Analyzer**: Identify deposit levels and credit/cash alternatives.
  - **Flight Compensation Estimator**: Check regulatory payouts on delay situations.
  - **Nomad Secure Checklist Generator**: Export pre-packed compliance structures.
- **Jamstack Code Exporter**: Immediate copy/paste system for optimized files (`index.html`, `styles.css`, `app.js`) to deploy straight to Cloudflare Pages or Vercel.
- **Logical CSS Properties**: Fully adapts typography flows with zero layout shifts (CLS) on extreme screen dynamic shifts.

## 🛠️ Local Tech Stack & Architecture

BookMeThat is styled with **Tailwind CSS** guidelines and leverages functional React components utilizing safe, responsive layout bounds.

```
/
├── index.html                  # Main application frame loader with the custom favicon
├── metadata.json               # Clean application classification boundaries
├── meta/
│   └── favicon.png             # The high-resolution BookMeThat custom favicon
├── src/
│   ├── App.tsx                 # Core application layout, UI shell, and exporter pipeline
│   ├── main.tsx                # React-Vite DOM mounting hub
│   ├── index.css               # Global tailwind styles and custom root system mappings
│   ├── types.ts                # Strict TypeScript contracts for data entities
│   ├── data/
│   │   ├── affiliates.ts       # Central source of truth for verified affiliate link databases
│   │   └── articles.ts         # Static optimized SEO destination guide materials
│   └── components/
│       ├── InteractivePlanner.tsx   # Travel packing checklist, search cache grids
│       ├── ComparisonCalculators.tsx # Logistics sliders, data planners, compensation tools
│       ├── SiloGuides.tsx           # Structured technical markdown search hubs
│       └── LegalPages.tsx           # FTC and GDPR static regulatory disclosure screens
```

### 📦 Quick Development Commands

1. **Install Dependencies** (runs backend initialization step):
   ```bash
   npm install
   ```

2. **Start Development Server** (runs local server in workspace mode):
   ```bash
   npm run dev
   ```

3. **Build Static Bundle** (compiles optimized static site assets in `/dist`):
   ```bash
   npm run build
   ```

4. **Verify Lints/Types**:
   ```bash
   npm run lint
   ```
